Solver selection and health checks no longer block the API during cold-start quantum-provider discovery. Startup pre-warms availability in the background; /health answers in milliseconds.

  • POST /v1/simulate — feasibility + confidence before you pay
  • webhook_url on /v1/optimize — solution pushed on completion
  • Signed execution receipts on every final job payload (HMAC-SHA256)
2026-08-17

Dockerfile + docker-compose + PRIVATE_API_KEY mode for private deployments. Same API, no blockchain settlement required.

All routes now declare auth mode (security: [], x-payment-info on /v1/optimize); duplicate payment options removed. Official x402 validator warnings reduced 34 to 1.
