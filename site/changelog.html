What changed

2026-10-22

fixSite copy matches the data-only surface

  • Removed the last references to free estimates and solver selection from the homepage and API reference — /v1/estimate does not exist.
  • The pricing step now documents what an agent actually gets for free: the 402 challenge carrying price, payee, asset and network.
  • Added an MCP section to the homepage and a measured latency table to latency & pricing.
2026-10-18

newOn-chain data only, plus a working MCP server

  • /v1/ml/* and the optimization surface are gone. The product is one paid data API: 15 routes across token, wallet, risk, whale, balance, NFT, history and cross-chain reads, from $0.004.
  • MCP server v0.5.0 at https://api.cortexcloud.org/mcp — Streamable HTTP, 15 paid tools plus cortex_capabilities and cortex_prices. Unpaid tool calls return the x402 challenge inside the result.
  • Bazaar registry rebuilt from the paid route table, so discovery cannot drift from what is billable.
  • Payment headers relay through the MCP server unchanged; it holds no funds and never signs.
