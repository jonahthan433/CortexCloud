CortexCloud

Optimization infrastructure for AI agents — discover, pay for, and execute classical, hybrid, or quantum optimization through a single API.

How an agent uses it

  1. Discover — /.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, or the MCP gateway at /x402/v1/mcp.
  2. Estimate (free) — POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and price for your QUBO/Ising.
  3. Pay & execute — POST /v1/optimize returns an x402 challenge (USDC on Base). Pay, then poll GET /v1/jobs/{job_id}.
curl -s https://api.cortexcloud.org/v1/estimate \
  -H 'content-type: application/json' \
  -d '{"problem_type":"qubo","n":4,"data":{"linear":[1,-2,3,-4],"quadratic":{"0,1":-1.5}}}'
