How an agent uses it

  
Three requests, zero accounts. The entire loop is machine-native: discover, estimate, then pay per call.

  

    
Discover
/.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and an MCP server at /mcp (4 tools). Agents find CortexCloud the same way a crawler finds a site.

    
Estimate — free
POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and exact price. No payment, no signup.

    
Pay & run
The endpoint issues an x402 challenge (USDC on Base). The agent settles, the job executes, and the result is returned or polled.

      
HTTP/1.1 402 Payment Required
x402Version: 2
accepts[0]:
  network:  eip155:8453   (Base)
  amount:   50000         ($0.05 USDC)
  payTo:    0x5a03…a143
# sign EIP-3009 -> resend with payment-signature -> 200

Common questions

  

    
Is the trial really free?
Yes. POST /v1/trial runs a real exact classical solve (up to n≤10) with no wallet and no USDC. You can try it from the button above before spending anything.

    
Do I need an API key or account?
No. Every call is authenticated by payment itself. Free endpoints need nothing; paid endpoints return a 402 challenge you settle in USDC on Base.

    
What does a paid call cost?
Optimization: classical $0.05, hybrid $0.10, real QPU $1.503 per job. AI from $0.004, research from $0.01, on-chain data from $0.004. POST /v1/estimate gives the exact price free before you pay.

    
What if a paid call fails?
Estimate, simulate and the solver encoders are always free, so you can validate a problem and price first. Paid charges apply per successful job, quoted up front by the 402 challenge.

    
Which chains and currencies?
USDC on Base (eip155:8453) via x402 today. No subscriptions, no cards, no invoices.

    
How do agents find the API?
Machine-readable discovery: /.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and an MCP server at /mcp.
