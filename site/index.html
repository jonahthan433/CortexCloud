How an agent uses it

Three requests, zero accounts. The entire loop is machine-native: discover, read the price, then pay per call.

Discover

/.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and /.well-known/agentsearch.txt. Agents find CortexCloud the same way a crawler finds a site.

Price — free

Call the endpoint without payment and the 402 challenge returns the exact price, payee, asset, and network. GET /v1/capabilities lists every route and price in one free request.

Pay & run

The endpoint issues an x402 challenge (USDC on Base). The agent signs an EIP-3009 authorization, resends with the payment header, and the data comes back in the same response.

What's callable

Eight data categories on one payment rail. Prices are published per route; the challenge is always free.

Token intelligence

$0.030

Flagship. One call returns deployment check, metadata, spot price, 24h change, optional age/liquidity/market-cap, and recent activity — each fact with its source, a checked_at timestamp, and explicit missing-data indicators.

Token prices

$0.004

Spot USD price and 24h change for any coin or contract, via CoinGecko with Alchemy fallback.

Contract & liquidity risk

$0.020

Risk verdict with evidence: contract existence, metadata, age/liquidity, recent mints and burns.

Wallet intelligence

$0.006

Native balance, holdings, recent activity, and counterparty relationships for any address.

Whale activity

$0.030

Large-transfer alerts with tx hashes, blocks, and timestamps.

Balances & history

$0.004

ERC-20 balances, NFT ownership, and normalized transaction history per chain. Batch routes take up to 20 addresses in one call for the flat $0.004 price.

Cross-chain comparison

$0.040

One contract across up to five chains: deployment, price, activity, and the best-liquidity chain — in one call.

Chain state

$0.004

Gas oracle (base + priority fee) and block lookups for every supported chain.

  -H "Content-Type: application/json" \

       "chain":"ethereum","coin_id":"usd-coin"}'

What just happened

      
The challenge (free): the endpoint answered 402 with the exact price ($0.030 in USDC on Base), the payee wallet, and the input/output metadata an agent needs to call it. You paid nothing.

      
Paying: your agent signs an EIP-3009 USDC authorization (gasless — no ETH needed) and resends with the payment-signature header. The response comes back as evidence-backed JSON: every fact carries its source, a checked_at timestamp, and an explicit missing indicator when data cannot be resolved.

Use it from an MCP client

  
The same 15 paid routes plus two free tools are exposed over Streamable HTTP. Point any MCP client at the URL — nothing to install, no key. A tool call without payment returns the x402 challenge inside the tool result, so the agent sees the price before it pays.

  

    
Endpoint
A single remote MCP server, version 0.5.0, served next to the API.
https://api.cortexcloud.org/mcp

    
Client config
For clients that speak remote MCP over HTTP.
{
  "mcpServers": {
    "cortexcloud": {
      "type": "http",
      "url": "https://api.cortexcloud.org/mcp"
    }
  }
}

    
Free tools
cortex_capabilities returns the live catalog; cortex_prices returns the price table. Both cost nothing and need no wallet.
