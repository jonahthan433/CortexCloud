How an agent uses it

Three requests, zero accounts. The entire loop is machine-native: discovery, a free estimate, then a pay-per-call solve.

Discover

/.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and an MCP server at /mcp (4 tools). Agents find CortexCloud the same way humans find a website.

Estimate — free

POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and exact price for a QUBO/Ising problem. No payment, no signup.

Pay & solve

POST /v1/optimize issues an x402/MPP challenge (USDC on Base). The agent settles, the job executes, GET /v1/jobs/{id} returns the solution.

Capabilities

Binary decision problems as QUBO/Ising: scheduling, routing, portfolio selection, staffing, facility placement, knapsack, max-cut. Sized classical solvers for everything; real QPU hardware for the hard stuff.

Classical

$0.05–0.25 by problem size

brute-force exact for n ≤ 20, simulated-annealing up to n = 5,000. Sized pricing: n ≤ 20 → $0.05 · 21–200 → $0.10 · >200 → $0.25.

Agent-native payments

No API keys. No billing portal. No human in the loop. The protocol negotiates the price, and the agent pays in USDC on Base via x402 (with MPP/Tempo as a second rail) — the same payment pattern registered with x402scan and the AgentCash Bazaar.
