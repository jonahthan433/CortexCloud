How an agent uses it

  
Three requests, zero accounts. The entire loop is machine-native: discovery, a free estimate, then a pay-per-call solve.

  

    
Discover
/.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and an MCP server at /mcp (4 tools). Agents find CortexCloud the same way humans find a website.

    
Estimate — free
POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and exact price for a QUBO/Ising problem. No payment, no signup.

    
Pay & solve
POST /v1/optimize issues an x402/MPP challenge (USDC on Base). The agent settles, the job executes, GET /v1/jobs/{id} returns the solution.

Agent-native payments

  
No API keys. No billing portal. No human in the loop. The protocol negotiates the price; the agent pays per call — via x402 (USDC on Base) or MPP (Tempo). Same pattern registered with x402scan and the AgentCash Bazaar.

  

    
PropertyCortexCloud

    
AuthenticationNone required — payments are the auth

    
Schemesx402 (HTTP 402 + signed settlement) and MPP (Tempo), USDC on Base, chain eip155:8453

    
Discovery/.well-known/x402, /.well-known/x402.json, AgentCash Bazaar, MCP registry io.github.jonahthan433/cortexcloud

    
BillingPer successful call, exact amount quoted before execution

    
SafetyInvalid requests rejected before settlement; no charge for unrunnable jobs; loss-making requests refused, never subsidized
