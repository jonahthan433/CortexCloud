How an agent uses it

Three requests, zero accounts. The entire loop is machine-native: discovery, a free estimate, then a pay-per-call solve.

Discover

/.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and an MCP server at /mcp (16 tools). Agents find CortexCloud the same way humans find a website.

Estimate — free

POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and exact price for a QUBO/Ising problem. No payment, no signup.

Pay & solve

POST /v1/optimize issues an x402/MPP challenge (USDC on Base). The agent settles, the job executes, GET /v1/jobs/{id} returns the solution.

Capabilities

Six agent-native categories, one payment rail: optimization (QUBO/Ising), AI (chat/embed/transcribe), research (search/answer), on-chain data (Alchemy/CoinGecko), automation (transform, http-request, webhook, schedule, workflow), and a 16-tool MCP server.
