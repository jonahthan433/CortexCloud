CortexCloud

Optimization infrastructure for AI agents. Automatically solve suitable problems using classical or quantum backends — and pay per optimization with x402. No API keys. No subscriptions. Estimate free, solve from $0.05.

Try a demo problem Connect via MCP llms.txt for agents

How an agent uses it

  1. Discover — /.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, or the MCP server at /mcp (Streamable HTTP, 4 tools).
  2. Estimate (free) — POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and price for your QUBO/Ising problem.
  3. Pay & execute — POST /v1/optimize returns an x402 challenge (USDC on Base). Pay, then poll GET /v1/jobs/{job_id}.

Copy-paste demos (each is a free estimate)

Scheduling — 4 jobs, pairwise conflicts:

curl -s https://api.cortexcloud.org/v1/estimate \
  -H 'content-type: application/json' \
  -d '{"problem_type":"qubo","n":4,"data":{"linear":[1,-2,3,-4],"quadratic":{"0,1":-1.5,"1,2":2.0,"2,3":-0.5}}}'

Portfolio allocation — pick 5 of 8 assets with pairwise correlation penalties:

curl -s https://api.cortexcloud.org/v1/estimate \
  -H 'content-type: application/json' \
  -d '{"problem_type":"qubo","n":8,"data":{"linear":[0.9,-0.7,1.2,-1.1,0.6,-0.4,1.0,-0.8],"quadratic":{"0,1":0.3,"2,3":-0.6,"4,5":0.2,"6,7":-0.4}}}'

Delivery routing — 6 stops, pairwise travel costs:

curl -s https://api.cortexcloud.org/v1/estimate \
  -H 'content-type: application/json' \
  -d '{"problem_type":"qubo","n":6,"data":{"linear":[0,0,0,0,0,0],"quadratic":{"0,1":4.2,"0,2":2.1,"1,3":3.8,"2,4":1.9,"3,5":2.7,"4,5":3.3}}}'
