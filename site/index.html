How an agent uses it

Three requests, zero accounts. The entire loop is machine-native: discover, estimate, then pay per call.

Discover

/.well-known/x402.json, /.well-known/bazaar, /llms.txt, /openapi.json, and an MCP server at /mcp (4 tools). Agents find CortexCloud the same way a crawler finds a site.

Estimate — free

POST /v1/estimate returns the recommended mode, algorithm, backend, runtime, and exact price. No payment, no signup.

Pay & run

The endpoint issues an x402 challenge (USDC on Base). The agent settles, the job executes, and the result is returned or polled.

Try a free example

Run a real CortexCloud request right now — no signup, no API key, no wallet. This solves a small portfolio-optimization problem and shows the exact answer.

POST /v1/estimate + POST /v1/trial — both free
curl -X POST https://api.cortexcloud.org/v1/estimate \
  -H "Content-Type: application/json" \
  -d '{"problem_type":"qubo","n":4,
       "data":{"linear":[1.0,-2.0,3.0,-4.0],
               "quadratic":{"0,1":-1.5,"1,2":0.5,"2,3":-2.0}}}'
Free — estimate and a real solve, no wallet. 

    

      
What just happened

      
Estimate (free): CortexCloud analyzed the problem, chose the exact classical solver, and quoted the price a paid run would cost — before you pay anything.

      
Solve (free): it returned the optimal answer and objective value. This is a real result from the live API, not a mock.
