Get started in minutes

Bring your own wallet with a little USDC on Base — that's the only setup.

Try it with curl

Hit any endpoint — you get a 402 challenge, pay it, retry. curl -i https://api.cortexcloud.org/x402/v1/data/prices

Install the MCP server

One line into Claude Code, Cursor, or any MCP client: claude mcp add cortexcloud -s user -- npx -y @cortexcloud/mcp

Read the spec

Interactive docs at /docs, machine-readable contract at /openapi.json.
