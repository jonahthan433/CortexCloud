Measured latency, published prices

Two things an agent needs before it spends money: how fast the endpoint answers, and exactly what it costs. Both are listed here. The numbers below are measured on the API instance itself, not estimated.

Server-side latency

30 sequential requests per route, measured over loopback on the API instance on 2026-10-22. This isolates the service from the network path between you and Cloudflare.

RouteKindp50p95
GET /healthfree4.1 ms5.4 ms
GET /v1/capabilitiesfree2.0 ms2.5 ms
POST /v1/data/token-price402 challenge1.8 ms3.3 ms
POST /v1/data/token-intel402 challenge2.4 ms4.1 ms

The 402 challenge rows measure challenge generation only — price, payee, asset and network — which is the free request an agent makes before paying. A paid response additionally waits on the upstream providers (Alchemy, CoinGecko) plus payment verification; that time varies with the provider and is not included above. We don't publish a latency figure we have not measured.

What this means for an agent: discovery and pricing are single-digit-millisecond server work, so the cost of asking "what does this cost?" is effectively zero. Budget your timeout around the provider call, not around the challenge.
